# 【Skill】日志脱水 (Log Dehydration)

> **目标**：从原始对话（Logs）中提取资产，分发至维度账本。
> **执行者**：🤖 管家 & 🎩 西风

## 🧹 脱水逻辑

1. **读取源数据**：
    - 读取 `history/logs/YYYY/YYYY-MM.md` 中属于 `## YYYY-MM-DD` 的对话。

2. **多维度分发 (Dimensional Dispatch)**：
    - **🏢 主业 (MainJob)**：关于 FaaS、发布、故障、职场博弈。
    - **🚀 个人资产 (NeoAgent)**：关于 NeoAgent 架构、代码、运营、技术调研。
    - **🏠 觉醒与生活 (LifeMindset)**：关于财务、消费、心智、家庭。
    - **格式**：`- MM-DD: [核心结论] 事实陈述。`
    - **目标**：追加到 `history/audit/ledgers/` 下的对应文件。

3. **深度思考集锦 (Wisdom Gallery)**：
    - 提取具有复利价值的审计结论。
    - 追加到对应维度账本的 `## 🧠 月度深度思考集锦` 部分。

4. **资产同步**：
    - 提醒用户更新 `project/wiki/audit/Principles.md`。

## 🎯 触发场景
- 用户指令：“脱水”、“总结今天”。
- 每天结束时自动执行。
