# 【Skill】归档日记

> **目标**：物理隔离单日审计，将单日日记分发至维度账本并销毁原始文件。
> **执行者**：🤖 管家

## 🧹 归档逻辑

1. **扫描与分发 (Dispatch)**：
    - 读取 `history/` 根目录下的所有日期命名的单日 `.md` 文件。
    - **逻辑**：将该文件的内容，按 **🏢 主业**、**🚀 副业**、**🏠 生活** 维度，分别分发至 `history/audit/ledgers/` 对应的维度账本中。
    - **格式**：`- MM-DD: [核心结论] 事实内容`。

2. **销毁 (Delete)**：
    - 成功分发后，立即 **删除 (rm)** 根目录下的单日 `.md` 文件。

3. **版本控制 (Git)**：
    - 归档操作完成后，自动执行 `git add .` 和 `git commit -m "chore: 维度账本分发归档"`。

## 🎯 触发场景
- 根目录出现单日日记文件时。
- `/skill 归档日记` 指令触发。
