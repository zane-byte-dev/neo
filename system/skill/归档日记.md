# 【Skill】归档日记

> **目标**：物理隔离旧日记，保持 `history/` 根目录极度清爽，只留“今天”。
> **执行者**：🤖 园丁

## 🧹 归档逻辑

1. **扫描与排除**：
    - 读取 `history/` 根目录下的所有 `.md` 文件。
    - **必须排除**：`日记模版.md`，以及当天的日记（比如今天是 `2026-02-25`，就严禁动 `2026-02-25.md`）。

2. **按月移动**：
    - 提取历史日记文件名的完整日期（格式：`YYYY-MM-DD`）。
    - 组装目标目录路径：`history/YYYY/MM/`。
    - 如果该月度目录不存在，自动执行 `mkdir -p` 创建。
    - 将文件 `mv` 到对应的月度目录下。

3. **执行原则**：
    - **静默搬砖**：不要说废话，不加“园丁已为您打扫”这种戏精垫片，直接汇报移动了哪些文件。
    - **内容只读**：严禁修改日记文件的内部文本，只准改变其物理存储位置。

4. **版本控制 (Git)**：
    - 移动操作完成后，自动执行 `git add history/` 和 `git commit -m "chore: 归档历史日记至月度目录"`。

## 🎯 触发场景
- 当用户抱怨历史文件太多时。
- 当用户要求清理日记本时。
- 发送 `/skill 归档日记` 指令时。
