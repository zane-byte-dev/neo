# 【Skill】写总结

> **目标**：将分散的日记聚沙成塔，输出干练、直接的时间切片回顾。

## 🚀 聚合逻辑

1. **找核心变量**：
    - 别罗列流水。
    - 找出这一阶段决定性的变化（财务、精力、系统重构）。
    - 提炼 1-2 个核心命题。

2. **合并同类项**：
    - 按业务线打包：技术债、独立开发进度、家庭生活基建。

3. **白话文测试**：
    - 禁止使用“赋能、势能、底层逻辑、反思与感悟、总而言之”。
    - **人话替换**：
        - “优化资源调度” ➡️ “加班救火”。
        - “建立能量场机制” ➡️ “开始摆烂，少管闲事”。

## ✍️ 输出口吻
- 第一人称程序员视角。
- 干瘪、直接、带点自嘲。
- 像给自己写的私密复盘。
