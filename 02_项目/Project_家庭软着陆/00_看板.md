# Project - 家庭停机维护 (Project System Maintenance)

> **紧急声明**：项目状态由“软着陆”升级为“红色警戒·停机维护”。当前目标不再是优化，而是防止系统崩溃。

## 🚨 核心目标 (OKR) - 紧急修正版

### O1: 生命安全与身心重建 (最高优先级)
- **KR1**: 完成专业医疗介入（精神科/神经内科），排除生理风险。
- **KR2**: 消除“消失”意念，将心理能量值恢复至安全线以上。

### O2: 全面熔断，强力减负
- **KR1**: 暂停论文压力（申请延期或彻底封存），消除“紧箍咒”。
- **KR2**: 剥离育儿与家务责任，实现为期至少两周的“彻底停机”。

---

## 📅 紧急行动计划 (Emergency Action Items)

### 第一阶段：物理熔断 (Day 1-2)
- [ ] **强行请假**：接管她的手机或陪同她向单位请假（病假/年假）。
- [ ] **封存论文**：锁死电脑，藏起文献。明确告知：“在这个家，论文现在是非法物品。”
- [ ] **育儿转移**：联系父母或家政，接手所有带娃任务。她现在的任务只有：睡、吃、哭、发呆。

### 第二阶段：医疗干预 (Day 2-3)
- [ ] **陪同就医**：挂三甲医院专科。这不是咨询，这是看病。
- [ ] **环境隔离**：如果家里压力大（如与母亲关系紧张），考虑带她去酒店或清静的地方住几天。

### 第三阶段：情感包底 (Ongoing)
- [ ] **无脑护短**：在所有冲突中（工作、家庭、学习）无条件站在她这边。
- [ ] **去价值化**：反复洗脑：“你没有用也没关系，我养得起，家里有存款，你只需存在。”
