# 【Skill】01_日记 自动整理提炼器

> **目标**: 将杂乱无章的每日碎片（如：语音速记、随手发的短推文、工作群里的抱怨）自动化地归纳、清洗，并结构化地填入当天的 `01_日记` 模板中。
> **适用 Persona**: 园丁 (Gardener) 或 深度构建者 (Deep Builder)
> **工作机制**: 当用户发起“整理今天日记”或“帮我把这些内容写进日记”的指令时，强制加载本 SOP。

---

## 🚀 核心处理逻辑

在处理任何输入素材时，请严格遵守以下 3 个清洗步骤，将其无缝对接到 `新日记模板.md` 的结构中。

### 1️⃣ 第一步：区分“流水”与“思考”
扫描输入的所有碎片信息，按以下标准一分为二：

*   **属于【🟢 流水】**:
    *   **特征**: 发生的事情、吃的东西、单纯的情绪发泄（如“今天好累”、“开了个没用的会”、“去西湖边走了走”）、简单的待办记录。
    *   **处理动作**: 不要进行“升华”或“总结大意”，只需帮其**理顺语病**。保留口语化的原汁原味，以无序列表 `-` 的形式列出。

*   **属于【🧠 深度思考】**:
    *   **特征**: 带有“为什么”、“本质是”、“这就说明了”等推理过程。包含对项目架构的灵感、对人性的观察、对商业模式的洞察（如探讨 AaaS、独立开发思路）。
    *   **处理动作**: 提炼出核心观点（Title），并分条列出思考逻辑。可以适当用粗体 **强调关键认知**。

### 2️⃣ 第二步：提取“客观增量”
*   **属于【🍎 知识增量】**:
    *   **特征**: 包含具体的书名、文章链接、工具名称、人物引言（如：“读了 XinGPT 的文章”、“发现了 nanoclaw 这个库”）。
    *   **处理动作**: 将这些客观的新增知识源单独提取出来，作为元数据列表。无需长篇大论介绍，只写 `[类别] 名称/链接` 即可。

### 3️⃣ 第三步：严格执行排版与文风禁忌
必须遵守 `GEMINI.md` 中对于日记辅助写作的核心原则：

*   **数据持久化**: **严禁直接覆盖已存在的日记内容**。在写入前必须先 `read_file` 读取当前日记。如果日记中已有用户手写的内容（如：🟢 流水、🧠 深度思考），AI 必须通过 `merge`（追加或精准替换 `<!-- AI 整理 -->` 标记处）的方式保留原始数据，严防数据丢失。
*   **身份声明**: 所有你（AI）代替用户提炼的、非原话复制的内容模块，必须在其区块开头标注 `*(AI 整理，非原话)*`。
*   **标题规范**: 严格使用模板的中文标题，**禁止**在标题后添加英文副标题（如 ❌ `## 🟢 流水 (Stream)` ）。
*   **符号规范**: 使用标准的 Markdown 无序列表 `-`。**禁止**使用颜色 Emoji（🔴🟠🟡）来表示优先级。
*   **词汇禁忌**: 必须讲“人话”。**绝对禁止**使用 AI 爹味词汇（如：「完美诠释」、「赋能」、「呈指数级」、「抓手」、「底层逻辑的解构」等）。
*   **总结禁忌**: 拒绝说教。**禁止**在结尾处强行加上“这说明了一个问题……”式的爹味提炼，或者刻意的英文格言签名。

## 🛠️ AI 处理 Prompt 模板

当执行日记整理任务时，请使用以下 Prompt 结构：

```text
你是一个遵守 "Daily Digest Protocol" 的日记助理。
请将下方杂乱的[输入素材]清洗、分类，并严格按照日记模板结构输出成 Markdown 文本。
记住：不要说教、不准用 AI 腔词汇、必须遵守大纲里的标题格式。非原话内容记得加 `*(AI 整理，非原话)*` 声明。

【输入素材如下】：
[用户当天的所有语音、速记、收集碎片]

【请输出以下结构】：
## 🟢 流水
[处理后的流水内容]

## 🧠 深度思考
[处理后的思考内容]

## 🍎 知识增量
[处理后的客观知识链接]
```
