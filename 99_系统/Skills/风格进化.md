# 【Skill】风格进化器

> **目标**：根据 `git diff` 分析我手改的痕迹，逆向提取红线并直接更新到原来的 Skill 文件里。

## 执行逻辑

1. **扫 Diff**：
    对比 AI 原稿和我改完的内容。
    - 看哪些虚词和客套话被我删了。
    - 看哪些大厂黑话被我替换成了动作描述。
    - 看我怎么把长篇大论敲碎成长短句的。

2. **抽红线**：
    从上面找出的差异里，抽出一条通用规则。不要只抓特定词，要抓语感。
    比如，把“禁止说深耕”提炼为“禁止用商业黑话，直接写干了几年”。

3. **刷配置**：
    把抽出来的通用规则，定成禁令，直接写进对应 Skill 文件的 `风格红线` 里面。

## 机器执行指令

收到我要“执行进化”的指令时，按这点跑：
1. 拿原稿和我改过的代码做对比。
2. 过滤掉事实层面的修改，只分析排版、句式和选词差别。
3. 给出一个包含新红线的 Markdown 补丁块。
4. 拿到授权后，直接调用工具覆写旧的 Skill 文件。
