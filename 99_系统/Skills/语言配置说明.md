# 🌍 Typeless 语言配置（中英）

日常仅使用**中文 + 英文**：中文为主，英文为常见词和项目相关词，**英文不翻译成中文**。

---

## 📝 配置项（.env）

```bash
# 输入语言（Whisper 识别）
INPUT_LANGUAGE=auto

# 输出语言
OUTPUT_LANGUAGE=auto
```

### INPUT_LANGUAGE

| 值 | 说明 |
|---|------|
| `auto` | 自动检测中英（推荐） |
| `zh` | 固定中文识别 |
| `en` | 固定英文识别 |

### OUTPUT_LANGUAGE

| 值 | 说明 |
|---|------|
| `auto` | **推荐**：中文为主，英文术语保持不翻译 |
| `zh` | 全部输出中文（会翻译英文） |
| `en` | 全部输出英文 |

---

## 🎯 默认行为（OUTPUT_LANGUAGE=auto）

- **中文** → 整理、润色后仍为中文  
- **英文**（术语、项目名、技术词等）→ **保持英文，不翻译**  
- **中英混合** → 中文部分润色，英文部分原样保留  

示例：

- 输入：「我们今天讨论了 React 和 TypeScript 的架构」  
- 输出：「今天我们讨论了 React 和 TypeScript 的架构。」

- 输入：「这个 API 的 endpoint 需要改一下」  
- 输出：「这个 API 的 endpoint 需要改一下。」

---

## 📚 常见配置

### 1. 中英混合，英文不翻译（默认）

```bash
INPUT_LANGUAGE=auto
OUTPUT_LANGUAGE=auto
```

### 2. 纯中文环境

```bash
INPUT_LANGUAGE=zh
OUTPUT_LANGUAGE=zh
```

### 3. 纯英文环境

```bash
INPUT_LANGUAGE=en
OUTPUT_LANGUAGE=en
```

---

## 🔄 修改配置

编辑 `.env` 后重启服务即可：

```bash
nano .env
# 修改 INPUT_LANGUAGE / OUTPUT_LANGUAGE

python3 typeless_server.py
```

---

## 繁体转简体

Whisper 有时会输出繁体。已做两件事：

1. **initial_prompt** 里要求「请使用简体中文」，尽量让模型直接出简体。
2. **后处理**：若已安装 `zhconv`，会自动把中文转成简体；未安装则只依赖 prompt。

建议安装以稳定得到简体：

```bash
pip3 install --break-system-packages zhconv
```

---

## 💡 小结

- 日常只用**中文 + 英文**时，保持 `INPUT_LANGUAGE=auto`、`OUTPUT_LANGUAGE=auto` 即可。  
- 英文常见词、项目名、技术词会**保持英文不翻译**，其余按中文为主润色。  
- 需要稳定简体输出时，可安装 `zhconv` 做繁转简。
