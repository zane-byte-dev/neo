# 【Skill】00_收集 自动分拣框架

> **目标**: 将杂乱无章的 `00_收集` 目录（例如零碎的推文、文章摘录、杂乱灵感）自动化、结构化地分拣到最终目的地（日记、项目、系统库或归档）。
> **工作机制**: 由 Agent (Gardener / Curator) 定期扫描 `00_收集` 文件夹，遵循以下判断标准对每个文件进行归类转移。

---

## 🚀 核心判定逻辑

Agent 在读取 `00_收集` 中的每一个文件时，必须严格依次通过以下 4 道“网眼”进行判定，**一旦满足某层条件，立即归档到对应层级，并终止后续判定**。

### 1️⃣ 第一层：是否为具体的“项目/竞品研究”？ (目标: `02_项目`)
*   **判定特征**:
    *   标题或内容明确指向某个具体的工具、开源库、SaaS 产品（如 "nanoclaw", "Typeless", "XinGPT 个人业务 Agent"）。
    *   内容包含完整的操作指南、代码实现、API 规范或竞品分析框架。
    *   包含清晰的商业模式分析或 MVP（最小可用产品）构建思路（符合独立黑客 Persona）。
*   **操作指引**:
    *   将文件移动到 `02_项目/` 中最相关的子目录（如 `NeoAgent/竞品分析`、`NeoAgent/参考资料` 等）。
    *   **核心提炼 (Insight Harvesting)**: AI 必须自动提取核心逻辑（如：工作流框架、变现公式、架构图解析），并以 `> **[AI Summary]**` 的形式置顶于文件头部，同时关联（Linking）到主项目看板（如 `00_Neo看板.md`）。
    *   **反向检索**: 如果内容提到已存在的工具或概念，主动在文件内添加 `[[双链]]` 以形成知识网。

### 2️⃣ 第二层：是否为深刻的“哲学思考/架构级方法论”？ (目标: `99_系统/架构` 或 `03_文章`)
*   **判定特征**:
    *   内容不依附于某个具体产品，而是讨论底层逻辑、人性本质、系统架构或人生战略（如 "Dan Koe Protocol"、"重新思考知识管理"）。
    *   包含长篇幅的理论推导、范式转移（Paradigm Shift）探讨。
    *   强烈匹配 "Deep Builder" 或 "West Wind" Persona 的特征。
*   **操作指引**:
    *   如果是关于个人底层系统的，移动到 `99_系统/`。
    *   如果是深刻的长文阅读笔记，移动到 `03_文章/` 或 `03_文章/记忆承载/`，作为后续长文输出的素材。

### 3️⃣ 第三层：是否为“日常碎碎念/灵感闪现/流水账”？ (目标: `01_日记`)
*   **判定特征**:
    *   内容零散、篇幅较短（如一条 X 推文的点子、一段随手记下的语音转换文本）。
    *   带有明显的时间属性和当下的情绪特征。
    *   不构成完整的项目逻辑，也不具备宏大的理论体系。
*   **操作指引**:
    *   将该内容（或包含该内容的推文卡片）提取出来，追加到当天 `01_日记` 文件的 `## 🍎 知识增量` 或 `## 🟢 流水` 模块中。
    *   提取完毕后，可将原碎片文件删除或移入归档。

### 4️⃣ 第四层：无明确价值的“信息噪音” (目标: 归档 `Archive` 或 删除)
*   **判定特征**:
    *   只是一句情绪化的发泄（如：“今天好累”、“这个烂市场”），没有任何增量信息或数据支撑。
    *   内容重复、过时的新闻播报，没有任何个人点评。
    *   纯广告、无脑营销内容。
*   **操作指引**:
    *   将其移动到 `00_收集/Archive` 目录（冷处理）。
    *   或者直接抛弃（Delete）。

## 🛠️ AI 处理 Prompt 模板

当 Neo Agent 执行清洗脚本时，应将文件内容附在以下 Prompt 之后：

```text
你是一个无情的信息分拣器，遵循 Neo 系统的 Root-Flat 架构，旨在消灭信息噪音。
现在有一份新收集的文档内容，请仔细阅读，并严格按照《00_收集 自动分拣框架》返回一个 JSON 结果。

返回格式必须是：
{
  "target_directory": "02_项目/NeoAgent/竞品分析",  // 或者是 01_日记, 00_收集/Archive 等
  "confidence_score": 95,                           // 1-100 的信心指数
  "action": "move",                                 // move(移动文件), extract_and_delete(提取内容到日记并删除原文件), archive(归档)
  "reasoning_summary": "该文档深入拆解了竞品架构并提出了 Agent 化的待办建议，属于典型的竞品分析，满足第一层判定标准。"
}

文档内容如下：
[附加文档内容...]
```
