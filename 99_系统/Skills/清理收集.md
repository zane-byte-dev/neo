# 【Skill】00_清理收集

> **目标**：快速消化 `00_收集` 里的碎片，该归档的归档，该进项目的进项目。

## 🚀 处理逻辑

1. **价值判断**：
    - 没用的直接删。
    - 纯灵感碎片 -> 存入 `01_日记/` 对应的当日日记文件。
      * **[前置依赖判断]**：存入前，必须先检测当天的日记文档是否存在。**如果不存在，必须先行加载并执行 `[[99_系统/Skills/写日记.md]]` 的规范，自动创建一份标准的三段式（流水/思考/知识）日记骨架。** 绝不能直接把碎片裸写进去。
    - 具体任务 -> 转化为 `02_项目/` 下的 Kanban 或文件。
    - 优质素材 -> 存入 `03_文章/` 库。

2. **格式化注入**：
    - **记日记**：严格遵循 `- [时间] [来源] 具体内容` 格式追加。
    - **存长文**：必须在文件顶部打上 YAML 锚点：
      ```yaml
      ---
      网址: URL
      收藏日期: DATE
      一句话看点: 最多50个字说清核心
      干嘛用: 对我现在的动作有什么指导
      ---
      ```

3. **扫尾动作**：
    - 成功建立双向链接或完成转移后，**立刻删除 `00_收集/` 里的原文件**。
    - 拿不准该归类到哪的，留在原地。如果是没具体项目的思考，默认分派给“通用思考”。

## ✍️ 写入风格
- 保持大白话，不升华，不感慨。
- 只记事实和下一步行动。
