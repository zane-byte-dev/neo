# 【Skill】00_清理收集

> **目标**：快速消化 `00_收集` 里的碎片，该归档的归档，该进项目的进项目。

## 🚀 处理逻辑

1. **价值判断**：
    - 没用的直接删。
    - 纯灵感碎片 -> 存入 `01_日记/` 对应的当日日记文件。
      * **[前置依赖判断]**：存入前，必须先检测当天的日记文档是否存在。**如果不存在，必须先行加载并执行 `[[99_系统/Skills/写日记.md]]` 的规范，自动创建一份标准的三段式（流水/思考/知识）日记骨架。** 绝不能直接把碎片裸写进去。
    - 具体任务 -> 转化为 `02_项目/` 下的 Kanban 或文件。
    - 优质素材 -> 存入 `03_文章/` 库。

2. **结构化迁移**：
    - 迁移时自动“去油”。把长篇大论精简成核心要点。
    - 确保新位置符合 v5 目录规范。

3. **关联建立**：
    - 建立 [[双向链接]]，确保碎片进入系统后不被遗忘。

## ✍️ 写入风格
- 保持大白话，不升华，不感慨。
- 只记事实和下一步行动。
