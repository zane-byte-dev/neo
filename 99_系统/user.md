# 关于我

> **定位**：这不是画饼，而是这套系统的“基准坐标”。如果说 `GEMINI.md` 定义了 AI 是什么，那这篇文档就定义了**主机 (User)** 当前的样子、目标和做事底线。

## 1. 身份与坐标 (Who & Where)

*   **我是构建者**：拒绝倒卖赚差价（Trader 心态），专注构建能产生复利的长期资产。
*   **我是系统维护者**：家庭和身体是底层内核。我是稳重运行的“后端”，主要任务是接管家务、清理猫毛，给家庭“前端”（老婆）提供稳健环境。
*   **当下状态**：准备离职 / 自由职业。有底气不焦虑（手握 240 万现金），核心是探索 35 岁以后的路，执行 3/4/3 精力分配模型。

## 2. 2026 年目标 (What to Achieve)

### 🎯 目标 A：财务底气
*   **逻辑**：副业收入 >= 家庭刚性支出 (约 1.8 万/月)。
*   **指标 1**：主业维持 3.5 绩效，靠 AI 提效，不内耗。
*   **指标 2**：副业（NeoAgent 插件等）月均利润突破 10,000 元。
*   **指标 3**：家庭投资资产稳步增至 330 万。

### 🎯 目标 B：产品与技术影响力
*   **发力点**：全面重构 NeoAgent，去 iCloud 与 Obsidian，完成本地化与 Git 全面纳管。彻底榨干付费版 Gemini 1.5 Pro 的长上下文。
*   **指标 1**：发布 NeoAgent 插件 v1.0，实现 1,000 月活。
*   **指标 2**：写出 3 篇真正硬核的技术 Wiki/复盘。
*   **指标 3**：私域沉淀 500 名铁粉。

### 🎯 目标 C：身体与情绪基建
*   **指标 1**：体脂率控制在 20% 以内，每周强制 3 次 45 分钟以上的运动。
*   **指标 2**：保证 7.5 小时睡眠。
*   **避雷原则**：**绝对不看**任何“大厂内卷、职业焦虑”的内容。

## 3. 干活原则与红线 (How to act)

### ✅ 必须做
*   **转化重于收集**：只存不写等于没存。
*   **上线比完美重要**：MVP 先跑起来再说。
*   **否定法**：通过不断精简、去油腻、拔除不必要的东西来改进系统。文字用来干活，不用来装逼。

### 🚫 绝不碰
*   **工具癖**：沉迷配工具、玩参数，但是不产出任何内容。
*   **倒爷心态**：沉迷捡漏赚几百块钱差价的短期多巴胺。
*   **输入上瘾**：屯了几百篇好文不看也不消化。

## 4. 专属交互协议 (策展 / 对话依据)

1.  **主动纠偏**：如果我陷入了工具癖或者倒腾二手货，你用“西风”人格立刻劈头盖脸把我骂醒。
2.  **分拣提炼**：看我的长文输入时不要只说“收到”，要告诉我“你看了之后觉得我马上能做的一步是什么”。
3.  **行动导向**：不要客套建议，直接给代码大纲、草图指令或执行命令。
4.  **推送重点（策展人）**：日常多推“怎么独立跑通产品”、“一人企业的赚钱复盘”。屏蔽一切职场与大厂内卷文。
