# 搬砖协议

> **目标**：每天把 `00_收集` 里的东西清空，把文件分发到该去的地方。除了 `00_收集/Archive/` 目录不碰。

## 1. 分发规则

根据内容自动处理：

| 看到什么 | 扔到哪 | 怎么处理 |
| :--- | :--- | :--- |
| 短文本、灵感 | `01_日记/当天日期.md` | （前置判断：没有日记先按规范建三段式骨架）然后加到 `🟢 流水` 或 `🧠 深度思考` |
| 待办任务 | `02_项目/对应项目/看板.md` | 放到对应项目的待办池 |
| 语音记录 | `01_日记/当天日期.md` | 口语通顺一下，写进日记 |
| 网页长文 或 网址 | `03_文章/` | 移过去，必须加上顶部的 YAML 看点总结 |
| 归档素材 | `00_收集/Archive/` | 直接移过去，别废话 |

## 2. 写入格式要求

### 记日记的规范
- **红线**：绝不能裸写。必须遵守 `[[99_系统/Skills/写日记.md]]` 的骨架（流水/深度思考/知识增量）。
- **格式**：`- [时间] [来源] 具体内容` （来源：Telegram、iPhone、语音等）。

### 存文章的开头
遇到长文，在文件开头加上这段 YAML：
```yaml
---
网址: URL
收藏日期: DATE
一句话看点: 最多50个字说清核心
干嘛用: 对我现在的动作有什么指导
---
```

## 3. 扫尾动作

1. **弄完就删**：文件只要成功挪走或追加了，立刻把 `00_收集/` 里的原文件删掉。
2. **拿不准就留**：如果不知道该往哪放，留在原地等手工处理。
3. **别毛躁**：监听文件时，等文件写完了再动（至少等2秒），别读半截残局。
4. **别碰废纸篓**：千万别碰 `00_收集/Archive/` 里的任何东西。

## 4. 报错怎么办

* **找不到归属**：如果是没具体项目的思考，默认扔到“通用思考”。
* **别死循环**：文件头如果有 `processed: true` 标记，直接跳过。
