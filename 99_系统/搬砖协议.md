# 搬砖协议

> **目标**：每天把 `00_收集` 里的东西清空，把文件分发到该去的地方。除了 `00_收集/Archive/` 目录不碰。

## 1. 分发规则

根据内容自动处理：

| 看到什么 | 扔到哪 | 怎么处理 |
| :--- | :--- | :--- |
| `#idea` 或 短文本 | `01_日记/当天日期.md` | 加到当天的流水里 |
| `TODO` 或 待办 | `02_项目/对应项目/看板.md` | 放到待办池 |
| 语音转文字 | `01_日记/当天日期.md` | 稍微通顺一下，写进日记 |
| 网页长文 或 网址 | `03_文章/Raw/` | 移过去，并写进 `03_文章/` 的目录或库里 |
| `#archive` 或 归档 | `00_收集/Archive/` | 直接移过去，别废话 |

## 2. 写入格式要求

### 记日记的格式
`- [时间] [来源] 具体内容`
来源就填：Telegram、iPhone、语音、Chrome。

### 存文章的开头
遇到长文，在文件开头加上这块：
```yaml
---
网址: URL
收藏日期: DATE
一句话看点: 最多50个字说清核心
干嘛用: 对我现在的动作有什么指导
---
```

## 3. 扫尾动作

1. **弄完就删**：文件只要成功挪走或追加了，立刻把 `00_收集/` 里的原文件删掉。
2. **拿不准就留**：如果不知道该往哪放，打个 `#不知道放哪` 的标签，留在原地等手工处理。
3. **别毛躁**：监听文件时，等文件写完了再动（至少等2秒），别读半截残局。
4. **别碰废纸篓**：千万别碰 `00_收集/Archive/` 里的任何东西。

## 4. 报错怎么办

* **找不到归属**：如果是没具体项目的思考，默认扔到“个人成长”或“通用思考”。
* **别死循环**：文件头如果有 `processed: true` 标记，直接跳过。

## 5. 保存对话

> 终端里有价值的聊天不能一旦关了就没了。要有存档。

* **存哪**：`01_日记/会话/年月/日期_聊了啥.md`
* **判断标准**：
    * **拉跨碎片/没啥用的查漏补缺**：直接扔到当天日记的结尾。
    * **推演决策/来回超 3 次的大论**：单开一个文件存，并关联到具体项目板上。
* **要求**：文件开头必须带有项目名、标签和日期。
