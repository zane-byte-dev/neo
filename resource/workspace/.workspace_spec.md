# Workspace 运行规范 (inkClaw)

## 1. 目录结构

### memory/ — AI 记忆层（Markdown）
- **memory/NOW.md**: 当前核心任务、今日焦点、优先级（短期记忆）。
- **memory/1-Daily/**: 日记、随手记、每日复盘。
- **memory/history/**: 历史会话摘要（长期记忆）。

### archives/ — 知识与产出归档
- **archives/Library/**: 结构化永久知识库。
    - `Career/`: 职业发展、工作记录。
    - `Life/`: 个人生活、人生轨迹。
    - `Wiki/`: 技术笔记、方法论、通用知识。
- **archives/Output/**: 已完成的产出（文章、报告、公号草稿）。

### SQLite（`data/neo.db`）— 运行时状态
以下数据存储在 SQLite，不再有对应目录：
- **Inbox / notes**: 碎片记录（`notes` 表）
- **Tasks**: 任务管理（`todos` + `tasks` 表）
- **提醒、定时任务、消息队列、会话历史**: 各自对应 SQLite 表。

## 2. 自动化操作规约

### 随手记录 (Daily)
- **位置**: `memory/1-Daily/`
- **逻辑**: 按日期创建文件（如 `2025-04-08.md`）。

### 知识沉淀 (Library)
- **逻辑**: 整理对话内容时，按类别归入 `archives/Library/` 下的对应子目录。

### 短期记忆 (NOW.md)
- **位置**: `memory/NOW.md`
- **逻辑**: 使用 `update_now` 工具更新；每次会话开始时注入 system prompt。

## 3. 维护原则
- 每次会话开始或执行复杂文件操作前，inkClaw 应先确认此规范。
- 严禁随意更改根目录结构。
