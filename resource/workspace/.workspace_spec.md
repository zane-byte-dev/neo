# Workspace 运行规范 (inkClaw)

## 1. 目录结构
- **0-Inbox/**: 外部抓取、未处理素材、临时灵感。
- **1-Daily/**: 日记、随手记、每日复盘。
- **2-Tasks/**: 任务管理。
    - `active.md`: 当前进行中的任务列表。
    - `backlog.md`: 待办池。
- **3-Library/**: 结构化永久知识库。
    - `Career/`: 职业发展、工作记录。
    - `Life/`: 个人生活、人生轨迹。
    - `Wiki/`: 技术笔记、方法论、通用知识。
- **4-Projects/**: 正在进行的具体项目文档。
- **5-Output/**: 已完成的产出（文章、报告、公号草稿）。
- **6-Archive/**: 已完成或失效的文档/任务归档。

## 2. 自动化操作规约

### 任务管理 (Task)
- **位置**: `2-Tasks/active.md`
- **格式**: `- [ ] 任务描述 #YYYY-MM-DD #标签`
- **逻辑**: 新增任务追加至末尾；完成任务修改状态为 `[x]` 并移动至归档。

### 随手记录 (Daily)
- **位置**: `1-Daily/`
- **逻辑**: 默认记录在以年份命名的文件（如 `2026 随手记录.md`），或按日期创建新文件。

### 知识沉淀 (Library)
- **逻辑**: 整理 Inbox 或对话内容时，按类别归入 `3-Library/` 下的对应子目录。

## 3. 维护原则
- 每次会话开始或执行复杂文件操作前，inkClaw 应先确认此规范。
- 严禁随意更改根目录结构。
