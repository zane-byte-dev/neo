## 主业（阿里 FaaS）

**核心项目**：VPC 隔离链路（x-fc-override-host → 流量验证 → 发布链路）；fc-mtop-gateway 全量发布；alifaas-api-server 去除冗余设计（用户请求与 DB 解耦）。

**最大挑战**：通义千问接入（2.4-2.7）是全程最高压事件：500 IP 上限被突破、Redis 压挂、CoreDNS 达上限，连续四天救火，最终通过流量透传 + Query Cache + Redis 读写分离 + 域名拆分（6 个独立域名）解决。

**策略升级**：从节能/逃避模式 → 价值萃取模式；将主业难题（MTOP、FaaS 治理）视为打磨个人架构方法论的磨刀石；绩效自评 AI 自动化生成（gitcommit + 周报 → 自评）。

**边界管理**：2 月复盘会后明确边界，风险转移给业务方，不再一人独扛；主业看板只保留 2 个保命底线任务。
