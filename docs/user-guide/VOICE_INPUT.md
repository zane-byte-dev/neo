# Web 语音输入

Neo Web Chat 支持通过麦克风录音、自动转写，把语音内容插入输入框。

## 如何使用

1. 打开 Neo Web Chat，在输入框右下角找到麦克风图标（发送按钮左侧）。
2. 点击麦克风开始录音，状态栏会显示「录音中」和计时。
3. 说完后点击停止按钮，系统将自动转写语音。
4. 转写完成后，文字会插入输入框，你可以继续编辑，然后手动发送。

> 语音转写完成后不会自动发送，需要你确认后手动发送。

## 界面说明

| 状态 | 图标/显示 | 说明 |
|------|----------|------|
| 待机 | 麦克风图标 | 点击可开始录音 |
| 录音中 | 红色脉冲 + 计时 | 正在采集声音，点击停止或取消 |
| 转写中 | 加载动画 | 正在识别语音，请稍候 |
| 完成 | — | 转写结果已插入输入框 |
| 错误 | 输入框上方红色提示 | 参见下方「常见问题」 |

录音中可点击：

- **停止**：结束录音并开始转写。
- **取消**：放弃本次录音，回到待机状态。

## 录音限制

- 单次最长录音 **90 秒**，超时后自动停止并转写。
- 最大音频文件 **25 MB**（通常 90 秒内不会触达）。
- 支持格式：`webm`、`ogg`、`mp4`、`wav`、`m4a`（由浏览器自动选择）。

## 环境要求

- 需要在 **HTTPS** 或 **localhost** 下访问，普通 HTTP 不支持录音。
- 支持 Chrome、Edge、Firefox 等现代浏览器；Safari 也支持但录音格式略有差异。
- 需要授予浏览器麦克风权限。

## 转写服务要求

语音转写由后端处理，需要至少配置以下之一：

| Provider | 说明 |
|----------|------|
| **OpenAI** | 使用 Whisper 模型，优先级最高，效果最佳 |
| **Gemini** | 使用 Gemini 1.5 Flash 多模态转写，作为 fallback |

如果两者均未配置，点击麦克风会提示「没有可用的转写服务」。  
前往 **设置 → 模型配置** 添加对应 API Key 即可启用。

## 隐私说明

- 录音只在点击停止后上传到 Neo 后端服务器进行转写。
- 录音中途取消则不会发送任何音频数据。
- 转写完成后，原始音频不会在服务端持久保存；只保留转写文本。

## 常见问题

### 提示「当前浏览器不支持录音功能」

你的浏览器不支持 `MediaRecorder` API。建议升级到最新版 Chrome、Edge 或 Firefox。

### 提示「语音输入需要安全连接」

当前页面通过 HTTP 访问。需要切换到 HTTPS，或在 localhost 下访问 Neo。

### 提示「麦克风权限被拒绝」

浏览器已阻止麦克风访问，修复步骤：

1. 点击地址栏左侧的锁图标（或「站点信息」）。
2. 找到「麦克风」权限，将其设为「允许」。
3. 刷新页面后重试。

### 提示「没有可用的转写服务」

后端未配置 OpenAI 或 Gemini API Key，前往 **设置 → 模型配置** 添加后重试。

### 提示「转写失败，请重试」

转写请求遇到网络错误或服务超时，等待片刻后重新录音即可。如果持续失败，检查后端服务日志。

### 录音期间附件或模型选择是否会丢失？

不会。录音状态机是独立的，不影响当前已选附件、项目或模型。
