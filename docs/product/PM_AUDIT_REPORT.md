## 一、产品概述

Neo 是一款「本地运行、自主规划、安全可控的 AI 工作搭子」，核心功能包括：AI 对话（含工具调用）、笔记本知识库、技能系统、模型管理、Telegram Bot、应用托管。整体完成度较高，设计语言统一，但仍存在若干 Bug、体验缺口和可优化点。

## 四、体验问题（UX/UI）

| # | 严重度 | 场景 | 问题描述 |
|---|--------|------|---------|
| U1 | 🔴 高 | 对话列表 | 存在多条都叫「今天的新闻」的会话，完全无法区分；自动命名逻辑未做去重处理 |
| U2 | 🔴 高 | 路由配置 | `Simple 上限 = -0.05`，负数阈值对普通用户极度反直觉，缺少参数说明（tooltip 或帮助文字） |
| U3 | 🟡 中 | Telegram Bot | 机器人 tab 将**运行控制**（开关）和**凭据配置**混在一起，职责不清；需先配置 Token 才能开启，但开关在上方，顺序误导 |
| U4 | 🟡 中 | 笔记本 | ✅ 已改善：无文章被选中时右侧空状态新增「新建文章」操作按钮 |
| U5 | 🟡 中 | 笔记编辑 | ✅ 已改善：手动保存笔记后显示成功 / 失败 toast 反馈 |
| U6 | 🟡 中 | 工具调用卡片 | “详情”按鈕仅 hover 时出现，**键盘用户和触屏用户无法发现此功能** | ✅ 已改善：ActivityItemCard 增加 tabIndex 和 Enter/Space 键盘支持 |
| U7 | 🟡 中 | 默认目录 | 输入框下方的"默认目录"标签不显示实际路径，用户不知道文件会存到哪里 |
| U8 | 🟡 中 | 模型选择 | 切换会话后模型选择**不跟随对话上下文**（始终是全局状态），多对话间切换时容易选错模型 |
| U9 | 🟢 低 | 侧边栏 | 笔记本折叠区域没有"暂无笔记本"的空状态提示，首次使用不知道如何创建 |
| U10 | 🟢 低 | 欢迎页 | 三个快捷卡片点击后仅填充前缀文字，**不会自动发送**，需用户手动补充再发送，引导感不强 | ✅ 已改善：卡片改为完整引导语并自动发送 |
| U11 | 🟢 低 | 对话管理 | 侧边栏对话项操作按钮（置顶/删除）**仅 hover 时展示**，移动端完全不可用 |

## 五、优化建议

| # | 价值 | 建议 |
|---|------|------|
| O1 | ⭐⭐⭐ | **对话标题去重**：自动命名时检测重复标题，附加时间戳或序号（如"今天的新闻 (2)"） |
| O2 | ⭐⭐⭐ | **路由配置简化**：提供"简单模式"下拉预设（保守/平衡/激进），隐藏高级数值参数，降低上手门槛 |
| O3 | ⭐⭐⭐ | **使用记录可视化**：添加折线图/柱状图展示每日 Token 消耗和费用，方便成本管控 |
| O4 | ⭐⭐⭐ | **模型选择持久化至会话**：用户在某会话手动选了某模型，切换回此会话时应还原该选择 |

| O7 | ⭐⭐ | **对话列表增加时间戳**：hover 时显示最后一条消息的发送时间，帮助区分同名对话 |
| O8 | ⭐⭐ | **安全确认 OFF 时添加警告样式**：关闭时使用橙红色，提升安全意识 |
| O9 | ⭐ | **笔记保存快捷键提示**：在 NoteEditor 顶部 bar 添加「⌘S 保存」文字提示 |
| O10 | ⭐ | **侧边栏折叠 tooltip**：折叠后悬浮于各图标时展示对应页面名称 |

## 八、本轮完成记录

- **F6 MCP 服务器管理 UI**：新增 `/api/mcp` 配置接口与「设置 / MCP 服务器」页，可新增、编辑、删除工作区 `mcp.json` 中的 MCP server，并在保存后刷新用户工具缓存。
- **F7 Webhook/Cron 管理 UI**：新增 `/api/crons` 定时任务配置接口与「设置 / 自动化」页，展示 Webhook 调用地址，并支持创建、编辑、删除 `memory/schedule.json` 定时任务。
- **F13 对话导入功能**：新增 `/api/session/import`，侧边栏菜单支持导入 Markdown/JSON 对话文件并生成新会话。
- **F12 跨笔记本搜索**：笔记本「全部」范围下明确使用跨笔记本搜索占位文案。
- **B8 设置页 hash → 路由**：设置页 tab 改为 `/settings/:tab` 路由，浏览器前进/后退可定位具体 tab。
- **O2 路由配置简化预设**：路由配置新增「保守 / 平衡 / 激进」预设，降低直接理解评分阈值的门槛。
- **O1 对话标题去重逻辑**：服务端创建首条用户消息标题时对同名标题自动追加序号。
