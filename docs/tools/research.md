# Research 工具

> 对指定主题进行深度网络调研，自动搜索多个来源、阅读网页内容，最终输出带引用来源的综合研究报告。

---

## 基本信息

| 属性 | 值 |
|------|-----|
| **工具名** | `research` |
| **分类** | `web` |
| **版本** | `1.0.0` |
| **依赖工具** | `search_web`、`fetch_url` |

---

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `topic` | `string` | ✅ | — | 要调研的主题或问题 |
| `depth` | `string` | ❌ | `"quick"` | 调研深度：`"quick"` 快速调研，`"deep"` 深入调研 |
| `language` | `string` | ❌ | `"中文"` | 报告输出语言，如 `"中文"`、`"English"` |

---

## 调研深度说明

### Quick（快速调研）

- 1-2 次有针对性的搜索
- 阅读 2-3 个最相关的来源
- 最多 8 个 agentic 步骤
- 适合简单事实查询、快速了解某个话题

### Deep（深入调研）

- 3-4 次搜索，从不同角度和关键词搜索
- 打开并阅读 3-5 个网页
- 交叉验证不同来源的信息
- 最多 15 个 agentic 步骤
- 适合技术调研、市场分析、竞品调查、文献综述

---

## 输出格式

报告以 Markdown 格式输出，包含以下结构：

```markdown
### 📋 研究报告：[主题]

**摘要**
（2-3句话概括核心发现）

**主要发现**
1. （发现1）
2. （发现2）

**详细分析**
（根据主题组织的详细内容，可分小节）

**引用来源**
1. [来源标题](URL)
2. [来源标题](URL)
```

## 使用示例

### 快速调研

```
帮我调研一下 WebAssembly GC 的最新进展
```

AI 会自动调用：
```json
{
  "name": "research",
  "args": {
    "topic": "WebAssembly GC 最新进展",
    "depth": "quick"
  }
}
```

## 工作原理

1. **接收参数**：解析 `topic`、`depth`、`language`
2. **构建受限工具集**：仅允许 `search_web` 和 `fetch_url` 两个工具
3. **生成系统提示词**：根据深度（quick/deep）和语言构建结构化的研究指导
4. **LLM 自主调研**：通过 `generateWithTools` 让 LLM 自主选择搜索→阅读→整合的流程
5. **返回报告**：输出结构化的研究报告（含引用来源）

---

## 与 `subagent` 的区别

| 对比 | `research` | `subagent` |
|------|-----------|------------|
| **定位** | 专注网络调研 | 通用子任务 |
| **工具范围** | 仅 `search_web` + `fetch_url` | 可自由指定任意工具 |
| **提示词** | 内置研究方法论指导 | 通用指令 |
| **输出格式** | 结构化研究报告 | 自由格式 |
| **步骤上限** | quick: 8, deep: 15 | 默认 10 |

## 适用场景

- 🔬 **技术调研**：了解某项技术的最新进展、最佳实践
- 📊 **市场分析**：某个领域的市场现状和趋势
- 🆚 **竞品调查**：产品或技术方案的对比分析
- 📚 **文献综述**：某个话题的综合概览
- ✅ **事实核查**：验证某条信息的真实性
