# Neo 产品体验审计报告（PM 视角）

**测试日期：** 2026-05-06  
**版本：** 本地开发版  
**测试方式：** UI 交互测试 + 代码审查  

---

## 一、产品概述

Neo 是一款「本地运行、自主规划、安全可控的 AI 工作搭子」，核心功能包括：AI 对话（含工具调用）、笔记本知识库、技能系统、模型管理、Telegram Bot、应用托管。整体完成度较高，设计语言统一，但仍存在若干 Bug、体验缺口和可优化点。

## 三、功能缺陷

| # | 优先级 | 模块 | 缺失功能 |
|---|--------|------|---------|
| F1 | 🔴 高 | 笔记本管理 | **无法删除或重命名笔记本**，用户创建后只能永久保留，UI 中无清理入口 |
| F2 | 🔴 高 | 对话列表 | **缺少批量管理操作**：已有 17+ 会话，无法批量删除或归档 |
| F3 | 🔴 高 | 应用 | **应用无 UI 管理入口**：只能手动向 `stateDir/apps/` 放文件，普通用户无法添加/删除应用 |
| F4 | 🟡 中 | 技能管理 | **技能无法排序或分组**，技能数量增长后难以管理 |
| F5 | 🟡 中 | 技能管理 | **无技能搜索功能**，仅支持列表浏览 |
| F6 | 🟡 中 | 模型管理 | **无 MCP 服务器管理 UI**，`mcp/` 后端功能完整但用户只能手动编辑配置文件 |
| F7 | 🟡 中 | 模型管理 | **无 Webhook/Cron 管理 UI**，后端已有实现但前端无入口 |
| F8 | 🟡 中 | 笔记本 | **笔记标签（tags）无筛选功能**，NoteEditor 支持写入 tags，但列表视图无法按标签过滤 |
| F9 | 🟡 中 | 使用记录 | **无可视化图表**，只有纯表格，看不出 Token 消耗趋势 |
| F10 | 🟡 中 | 使用记录 | **历史数据访问困难**，日期选择器只能切换月份，无快速跳转或范围选择 |
| F11 | 🟢 低 | 对话搜索 | **搜索结果无高亮**，匹配词在标题中不高亮显示 |
| F12 | 🟢 低 | 笔记本 | **无跨笔记本搜索**，只能在当前笔记本内搜索 |
| F13 | 🟢 低 | 对话 | **无法导入对话**，有导出 Markdown 但无对应导入功能 |

## 四、体验问题（UX/UI）

| # | 严重度 | 场景 | 问题描述 |
|---|--------|------|---------|
| U1 | 🔴 高 | 对话列表 | 存在多条都叫「今天的新闻」的会话，完全无法区分；自动命名逻辑未做去重处理 |
| U2 | 🔴 高 | 路由配置 | `Simple 上限 = -0.05`，负数阈值对普通用户极度反直觉，缺少参数说明（tooltip 或帮助文字） |
| U3 | 🟡 中 | Telegram Bot | 机器人 tab 将**运行控制**（开关）和**凭据配置**混在一起，职责不清；需先配置 Token 才能开启，但开关在上方，顺序误导 |
| U4 | 🟡 中 | 笔记本 | 无文章被选中时右侧显示「从左侧选择一篇文章」，但**没有引导性操作按钮**（如"新建笔记"），空状态体验差 |
| U5 | 🟡 中 | 笔记编辑 | 保存笔记后**无成功 toast 反馈**，用户不确定是否保存成功 |
| U6 | 🟡 中 | 工具调用卡片 | "详情"按钮仅 hover 时出现，**键盘用户和触屏用户无法发现此功能** |
| U7 | 🟡 中 | 默认目录 | 输入框下方的"默认目录"标签不显示实际路径，用户不知道文件会存到哪里 |
| U8 | 🟡 中 | 模型选择 | 切换会话后模型选择**不跟随对话上下文**（始终是全局状态），多对话间切换时容易选错模型 |
| U9 | 🟢 低 | 侧边栏 | 笔记本折叠区域没有"暂无笔记本"的空状态提示，首次使用不知道如何创建 |
| U10 | 🟢 低 | 欢迎页 | 三个快捷卡片点击后仅填充前缀文字，**不会自动发送**，需用户手动补充再发送，引导感不强 |
| U11 | 🟢 低 | 对话管理 | 侧边栏对话项操作按钮（置顶/删除）**仅 hover 时展示**，移动端完全不可用 |

## 五、优化建议

| # | 价值 | 建议 |
|---|------|------|
| O1 | ⭐⭐⭐ | **对话标题去重**：自动命名时检测重复标题，附加时间戳或序号（如"今天的新闻 (2)"） |
| O2 | ⭐⭐⭐ | **路由配置简化**：提供"简单模式"下拉预设（保守/平衡/激进），隐藏高级数值参数，降低上手门槛 |
| O3 | ⭐⭐⭐ | **使用记录可视化**：添加折线图/柱状图展示每日 Token 消耗和费用，方便成本管控 |
| O4 | ⭐⭐⭐ | **模型选择持久化至会话**：用户在某会话手动选了某模型，切换回此会话时应还原该选择 |
| O5 | ⭐⭐ | **导出 Markdown 增强**：包含工具调用记录、思考过程、时间戳等元数据 |
| O6 | ⭐⭐ | **技能触发词可见性**：在技能卡片上直接展示触发词摘要，方便用户记忆如何激活 |
| O7 | ⭐⭐ | **对话列表增加时间戳**：hover 时显示最后一条消息的发送时间，帮助区分同名对话 |
| O8 | ⭐⭐ | **安全确认 OFF 时添加警告样式**：关闭时使用橙红色，提升安全意识 |
| O9 | ⭐ | **笔记保存快捷键提示**：在 NoteEditor 顶部 bar 添加「⌘S 保存」文字提示 |
| O10 | ⭐ | **侧边栏折叠 tooltip**：折叠后悬浮于各图标时展示对应页面名称 |

## 六、综合评分

| 维度 | 评分（满分10） | 说明 |
|------|-------------|------|
| 功能完整度 | 7.5 | 核心对话 + 工具链 + 笔记本已成型，但管理类功能（删除、批量、图表）缺失 |

| 信息架构 | 7.0 | 对话/笔记本/设置层级清晰，但设置内部三 tab 内容密度不均 |
| **综合** | **7.3** | 有明确产品思路，技术积累扎实，需补足运营/管理类体验短板 |
