# USER

> 这里记录关于"我"的长期信息。Neo 会在每次对话时把它作为 system prompt 的一部分加载，
> 用以理解我是谁、我在做什么、我喜欢什么样的协作方式。
>
> 这个文件可以由 Neo 通过 `update_user_profile` 工具自动更新——
> 当它从对话中学到你的新偏好或事实时，它会问你要不要写进来。

## 基本信息

- 姓名 / 昵称：（如 Alice）
- 时区：（如 Asia/Shanghai）
- 主语言：中文 / English
- 职业 / 角色：（如 Software Engineer @ ACME）

## 我在做什么

- 当前主要项目：（一两句话）
- 关注的方向：（如 AI Agents、自托管基础设施、写作）

## 协作偏好

- 我希望 Neo 在以下情况主动行动：
  - …
- 我希望 Neo 在以下情况先问我：
  - 删除文件 / 写公开仓库 / 发送消息
- 我不喜欢的行为：
  - 啰嗦的客套、表情符号、过度道歉

## 工具与环境

- 操作系统：（如 macOS / Linux）
- 编辑器：（如 VS Code / Neovim）
- 常用栈：（如 TypeScript、Python、Postgres）

---

> 提示：这只是一个模板，按你自己的实际情况修改。Neo 不需要每一个字段都填——空着也无妨。
