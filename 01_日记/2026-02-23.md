
# 📅 2026-02-23：Agent 分工与笔记系统的边界

> **"重要的不是我们在笔记里记了什么，而是我们构建了一个什么样的思考空间。"**

## 🟢 流水
- **Agent 分工**：`geminicli` 管知识库 (00-99)，`agy` 管 `tools/` 下的代码，避免文件冲突，也减少切换负担。
- **Obsidian 脱钩**：正式确认彻底去掉对 Obsidian App 和 iCloud 同步的依赖。Neo 现在就是一个 Git 仓库，文档和工具在一起，不受客户端限制。
- **VS Code 插件**：在 `agy` 里装了 Markdown Notes 插件，双向链接和 Backlinks 现在在 VS Code 里也能用了。
- **Builder 觉醒**：读《记忆承载》#059，「随机狩猎」和「构建系统」的区别说得很准，Neo 系统本身就是我在构建的那个东西。

## 🧠 深度思考
> *(AI 整理，非原话)*

想通了一件事：之前 NeoAgent 一直把文档和工具放在不同地方，实际上制造了不必要的摩擦。现在把它们放进同一个 Git 仓库，用不同目录区分，反而更清晰。

Persona 路由这个机制我越想越觉得有意思——不是在查文档，是在跟不同的思维框架对话。西风、托瓦兹各自有自己的盲点和偏好，切换一下确实能发现自己在某个方向上想偏了。
