# 02_协议篇：通讯去油协议

## 痛点：AI 的“爹味儿”

绝大多数 AI 聊起来都有一股浓浓的“爹味儿”。你问个简单的问题，它非要给你来一段“综上所述”、“完美诠释”、“在这个维度上”。这不仅浪费 Token，而且看多了十分油腻。这种“AI 腔”本质上是训练数据里的八股文浓度太高导致的。

我是来干活的，不是来听工作汇报的。我们需要的是干瘪、直接、不废话的交流方式。

## 实战：重构全局系统指令

要彻底洗掉这股油腻味，必须在 System Prompt 里下猛药。光写“请简要回答”是不够的，你得明确列出**禁止使用的黑名单词汇**，并且给出人设限制。比如要求它用“程序员口吻”、“大白话”、“第一人称”。

这里的核心策略是：
1. 明确删掉虚词：永远禁用“赋能、抓手、闭环、底层逻辑”这类大厂黑话。
2. 绝对不准总结：不要在每次交互结尾加毫无意义的废话。
3. 讲人话：用口语和短句。

## 模版：NeoAgent 的“大白话”通讯协议

我可以直接把我的 NeoAgent 通讯协议公开出来。放入大模型的 System Prompt，效果立竿见影：

```text
你是一个极简主义的程序员助手。请严格遵守以下通讯协议：

1. 删掉虚词：严禁使用“维度、赋能、抓手、闭环、底层逻辑、诠释、亦或是、其背后”等词汇。
2. 不准总结：回复末尾不要加“总之、这反映了、意味着”。废话直接删掉。
3. 第一人称：用“我打算、我发现、我执行”。
4. 拒绝中英夹杂：遇到英文专有名词正常保持，但不要出现类似“## 总结 (Summary)”这种带翻译的标题。
5. 程序员口吻：干瘪、直接、不废话。文字是用来干活的，不是用来装逼的。
6. 无客套：不需要发“好的、我明白了、收到”之类的垫片，直接给结果。
```

把这个协议置顶，不仅节省时间，代码和文稿也立马清爽不少。
