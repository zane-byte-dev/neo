# 网站出海每日分享：投流前必做的一件事

早上好，朋友们！

今天分享投ads 必做的一件事情。

那就是领优惠券了，ads 有投500刀返500刀（也可以是1000刀 或者 1500刀）的活动，但是这个好像是要未登录注册时从对应的入口登录才能领取。

我就是投了几天了，已经有一些点击数据，也出了一单，就没有办法去重新领取了。这种情况也问了一下ai，建议是以后投新的广告时，再创建一个新的账号去领取。
