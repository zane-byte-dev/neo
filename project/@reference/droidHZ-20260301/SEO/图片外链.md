# 网站出海每日分享：图片外链

早上好，朋友们！
今天分享一下图片外链。
什么是图片外链？ 图片外链 = 图片放在你的网站上，但被展示在别人的平台（比如 Pinterest），用户一点击图片，就回到你的网站。

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUfFfvvpobRiboaxzV23xcPnfvwNuYViaQdKUibYoxRbk0Fkib9h8UOOIGCdgSo3B51J92e5BOMC6X8rsA/640?wx_fmt=png&from=appmsg)

图片外链，可以低成本引流，比如你在pinterest 上传了图片，设置了网站，用户看到你图片的时候，就可以跳转到你的网站
对SEO也有加成，相当于设置了外链和曝光
在Pinterest上，你可以选择通过一个图片url 添加地址，或者是直接输入你网站的地址。都可以把图片和网站关联起来。
