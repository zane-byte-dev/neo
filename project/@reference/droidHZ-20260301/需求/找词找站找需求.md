# 网站出海每日分享：找词找站找需求

之前分享了 词找词 ，搜索即需求。
今天我们来看看词找站、站找词、站找站。

词找站：
这个也是我们用的最多的，你有一个搜索需求，直接用这个词去进行Google 搜索，找到相关的网站。

可以通过https://query.domains/
找到关键词相关的域名网站。
