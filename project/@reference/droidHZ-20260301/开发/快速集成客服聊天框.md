# 网站出海每日分享：快速集成客服聊天框

早上好，朋友们！

今天分享crisp 客服聊天框，我们一般会在网站留联系邮箱，但是这样用户联系你的成本太高，如果遇到问题用户可能就放弃你的网站，可能也会有一些致命的BUG 无法被发现。如果页面有一个客服聊天框，用户可以及时的反馈问题，那么就能减少这方面的折损。 同时用一个聊天框反馈问题，也会显得你的网站更加的专业，也能让用户更加信任你的网站，促进支付转化。

那么如何集成呐？
首先进入https://app.crisp.chat/ 网站进行登录注册。
在 控制台 > Settings > Workspace Settings > Setup & Integrations。找到 Website ID。

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUdpXeFd8s7Vjwu7jJTaHwrlOLFNbrXsABJVx4740icj59EFvxicQj8J8lhA4ueVEUOR2rNzS2fOgLRA/640?wx_fmt=png&from=appmsg)

我使用的是mksaas 模板，是只需要配置NEXT_PUBLIC_CRISP_WEBSITE_ID 为Website id 的值就可以了。
同时在对应的 website.tsx 配置文件中将 enableCrispChat 设置为 true 就开启了这个功能。

如果是其他模板其实就是HEAD插入一段代码，这个集成的代码也可以在上面Setup & Integrations 页面找到，可以试试让AI直接给你加上这个功能。

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUdpXeFd8s7Vjwu7jJTaHwrlapRZjQaia3I8aJlU45LHP8fxia59v7ZvCibSMXr84EwoZKg3Y9fUoGyRg/640?wx_fmt=png&from=appmsg)

接入之后crisp的后台就能够收到消息了。
