# 网站出海每日分享：必不可少的神器

早上好，朋友们。
今天分享一个SEO 必备插件AITDK
以flux1.ai 网站来看看他支持哪些能力

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUf9L1zibLrThM25o4oDIiaR9R2EmEwRleibx7kg5sia7zBMCibbreViblg2DTkibcJmCkgHicxSaoYt7Cuzmg/640?wx_fmt=png&from=appmsg)

Overview 可以清晰的看到该网站的。
1.Title 、Description 是否符合长度要求
2.Keywords 是什么，建议是不设置
3.url 和 Canonical（规范网址）， Canonical是必须要设置，否则会分散网站权重
4.域名相关信息
5.相关文件是存在favicon、robots.txt.sitemap.xml
6.是否接入Google Analytics 和 Google Adsense
7.网站字数统计，语言
8.h1到h6的数量
9.图片数量，图片alt 数量
10.链接数量，内外链区分，dofllow区分

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUf9L1zibLrThM25o4oDIiaR9RoHxJ2icHZMjEHRZtbZkHbiasHk35GYY8Wuia0uhak3Zh8rhfrNH7DDlvQ/640?wx_fmt=png&from=appmsg)

Traffic
1.可以看到网站的流量、跳出率、平均访问页面数、停留时间、全球排名、所在国家排名的基本数据信息
2.最近3个月流量信息
3.流量来源
4.流量地区来源
