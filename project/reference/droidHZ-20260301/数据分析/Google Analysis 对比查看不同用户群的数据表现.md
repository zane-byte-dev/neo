# 网站出海每日分享：Google Analysis 对比查看不同用户群的数据表现

早上好， 朋友们！
今天分享Google Analysis如何对比查看不同的用户群的数据表现。
顶部添加比较对象

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUewC7icoJcyYWCE5bR9VEVY8H1d5hVOkUkbzZNqicEdSWHJ94sPlTPoVb4XU6ib4NxaJiaJPWYqT4EvoQ/640?wx_fmt=png&from=appmsg)

进入比较对象的时候，有一些默认的用户区分，比如你可以直接选择移动端，和整体对比一下。还可以右上角点击新建，自定义的人群对象

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUewC7icoJcyYWCE5bR9VEVY8VTcJaoAUvuq1wVUkNbFgOQXdJtHibicMVT4Yo99mSv0IJGo1dYxrp42Q/640?wx_fmt=png&from=appmsg)

选择你要区分的维度，比如国家、操场系统之类的，有很多维度可以选择。我们这里就以不同的渠道来源为例。选择带来回话的来源，再选择bing,这里可以多选

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUewC7icoJcyYWCE5bR9VEVY8E6iaSjEtgzycdh07kVwlZukruTFlWTZxlqohwlETBNBYoqHRNY56cmA/640?wx_fmt=png&from=appmsg)

保存之后，你就可以直观的看到不同来源的数据表现，可以左右进行对比。Google analysis 所有的报告面板 都支持这样对比查看的，你就可以方便的看到不同人群的留存，付费情况是什么样的

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUewC7icoJcyYWCE5bR9VEVY8v8vwAJKvXDJegofCq2XPf2uX3zqoOp3yvjxicxgrNruAJ6KtHTFnZfA/640?wx_fmt=png&from=appmsg)
