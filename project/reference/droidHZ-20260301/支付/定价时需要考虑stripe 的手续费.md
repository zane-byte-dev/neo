Stripe 常见是 2.9% + $0.30/笔，重点在这个 $0.30 是固定的。
比如卖 $4.99，手续费接近 10%；
卖 $9，也要 7%+；
到 $19 / $29 才慢慢回到 5% 左右。

![image](https://mmbiz.qpic.cn/mmbiz_png/gG3yexRibCUfyoN0k1WDvibYMicktXuDaFdk9tbibwlP4FgOzva6j3Ox95ia5chYUYfyaENC1lslypRcsG3cTTMialJw/640?wx_fmt=png&from=appmsg)

如果再叠加国际卡、换汇，实际成本会更高。
所以低价档需要考虑里面很大的一个手续费率折损。定价时可以按照“最坏手续费”倒推。
